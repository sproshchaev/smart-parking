Теория и Best Practises Акт I

// 1) String - не null 2) String? - null-абле
// 2) val x: String? = "..."
// 3) Безопасный вызов ?.
// 4) Оператор Элвиса ?: // замена if-else на строку
// 5) Умное приведение if (x != null) => внутри считаем String
// 6) !! превращает String? -> String (антипаттерн)
// 7) takeIf, через лямбду с параметром it
// 8) диапазоны 8..9, проверяем через in
// 9) Тело-выражение =

// Лучшие практики
// 1) Использовать String? когда возможно null
// 2) !! не исп
// 3) Допускаем null только на границе функции
// 4) Ветка неудач сразу: номер распознан, номера нет, не определен
// 5) (?. и ?) vs ручные проверки: raw?.trim()?.uppercase() vs (3 x if)
// 6) Писать тип явно там где правая часть не однозначна val fromCam: String? = " а123вс77 "
